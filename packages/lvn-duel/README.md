# @fomean/lvn-duel — дуэль-инкрементор для Elvin

Боевой модуль `.lvns`: дуэль один-на-один, где **очередь действий растёт с
каждым обменом**. Первый обмен — одно действие, второй — два, дальше три,
четыре, пять. Оба бойца планируют вслепую, потом очередь прокручивается такт
за тактом. Бой сам эволюционирует от рефлекса к планированию.

Ставится одной строкой, ничего в движке менять не нужно.

```
include "@fomean/lvn-duel/duel.lvns"

дуэль_хп = 6
дуэль_хп_макс = 6
враг_хп = 8
враг_хп_макс = 8
враг_имя = "Скелет"
duel()

if дуэль_исход == "победа" -> победа
if дуэль_исход == "пал" -> смерть
-> ничья
```

## Установка

```sh
lvnconv deps add "@fomean/lvn-duel" "github:fomeanator/lvn-duel@v0.1.0"
lvnconv deps sync
```

Подробности пакетной системы — [docs/packages.md](https://github.com/fomeanator/elvin/blob/main/docs/packages.md)
в репозитории движка.

## Что внутри механики

**Матрица такта.** Удар × удар — размен: у кого больше **темпа**, тот бьёт
первым и вдвое сильнее (темп сгорает). Удар × блок — удар съеден, защитник
копит `+1` темп. Блок × блок — пустой такт. Темп и есть экономика боя: вечный
блок не выигрывает (урона нет), вечный удар кормит чужой банк — играть
приходится по паттерну противника.

**Никакого рандома** (модель Punch-Out!!): у врага фиксированный паттерн,
тычок подсказывает только ПЕРВЫЙ такт обмена, остальное — память игрока. На
половине здоровья враг «звереет»: вторая строфа паттерна, объявляется явно.
Новый противник — две строки-таблицы, не новый код:

```
паттерн_обычный = list("удар", "удар", "блок", "удар", "блок")
паттерн_ярость  = list("удар", "блок", "удар", "удар", "удар")
```

**Навыки занимают такт очереди** и растут от применения (владение в %):
💫 оглушение против его удара за темп, 🔨 пробив сквозь его блок с риском.
Опыт по заслугам: промах `+1`, эффект `+3`, крит `+6`; ступень =
`1 + floor(владение / 25)` — каждая ступень меняет числа, а не «+урон».

**Сцена обмена всегда 6 секунд**: такт = `6 / кол-во тактов`. Ранние обмены
смакуются, поздние уплотняются, общий ритм боя постоянен.

## Контракт

Глава выставляет ДО вызова:

| Переменная | Что это |
|---|---|
| `дуэль_хп`, `дуэль_хп_макс` | герой (сгорают со смертью дня) |
| `враг_хп`, `враг_хп_макс` | противник |
| `враг_имя` | подпись для HUD |
| `день` | номер дня (для HUD) |
| `навык`, `навык_выбран`, `влад_оглушение`, `влад_пробив` | владение навыком ПЕРЕЖИВАЕТ день: тело сгорает — руки помнят |

После `duel()` читает `дуэль_исход`: `"победа"` | `"пал"` | `"затянулась"`.

Фон ставит глава (у команды `bg` не интерполируется `sprite_url`).

## Арт

Спрайты пакета лежат по контракту `/content/packages/lvn-duel/…` —
`deps sync` кладёт их в контент игры сам. Чтобы перерисовать под свою игру,
залей свои PNG по тем же путям: библиотеку править не нужно.

В комплекте — серые болванки (кнопки, полоски, скелет, руки), чтобы модуль
играл из коробки.

## Баланс

Матрица проверена симуляцией:

| Стратегия | Исход |
|---|---|
| только удар | пал на 3-м обмене |
| только блок | ничья — блоком не выиграть |
| читает паттерн, без навыков | победа на 5-м обмене, ♥3 из 6 |
| читает + любой навык | победа без единой раны |

Тугой умрёт, внимательный пройдёт с первого раза — знание паттерна и есть сила.
