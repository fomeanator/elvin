# Реакции героини витрины — анализ и предложение системы

*08.09.2026. Заказ Ильи: «микрофишки, которые сильно оживят» → «надо систему
нормальную создать» → «вынести в отдельный настраиваемый через манифест
механизм».*

## 1. Что просили (и что это на языке сцены)

| Фишка | На языке сцены |
|---|---|
| В магазине героиня слева и на 5 % крупнее | композиция вкладки: слот `left`, план 1.05 (вместо 1.0 на боковых) |
| При переходе в магазин — радость | ось `emotion` = `happy`, пока игрок в комнате «магазин» |
| 10 с бездействия на главной — недовольство | таймер бездействия → `emotion` = `discontent`, сброс любым касанием |
| Покупка: удивление 1.2 с → радость 1.3 с → сон 2 с → нейтральная | КЛИП: последовательность смен эмоции с паузами и возвратом |

Первая строка — числа композиции (где стоит, какой план). Остальные три —
ПОВЕДЕНИЕ: событие → клип. Их и надо выносить в механизм.

## 2. Что в движке уже есть (прочитано по коду, не по памяти)

- **Эмоция = ось куклы.** Слой `face` собирается по шаблону
  `face_{pose}_{emotion}` (`manifest.json`, каталог героини); у героини 20
  лиц на позу `west`: anger, boredom, delight, discontent, dreamy, fear, flirt,
  happy, horny, idle, medium, offence, sad, sarcasm, shame, sleep, smirk,
  surprised, tears, thoughtfulness. Любое свободное поле команды актёра — ось
  (`VnStage.AxesFrom`), то есть `actor mara happy` уже понятен сцене.
- **Смена лица не мелькает.** Смена облика видимого актёра идёт кроссфейдом
  0.20 с (`VnTheme.LookSwapSeconds`) через прокси-композит: старые слои
  держатся, пока новые не доехали (`WorldActor.CrossfadeArtSwap`).
- **Кукла витрины ставится настройками, а не командой.** `LvnPrima.Stand` →
  `VnStage.ShowMenuDoll` кладёт позу на слой `Menu` партитуры
  (`LvnStageScore`): слой эксклюзивен, кадр главы не трогает. Добавить в позу
  `emotion` — одно поле.
- **Язык уже умеет клипы.** `actor <id> <emotion>`, `wait ms=1200`, метки,
  `call`/возврат, `anim` с параллельными каналами, `sfx`, условия по
  переменным (`howto/CHEATSHEET.md`). Исполняет `LvnPlayer(doc, ILvnStage)`;
  `wait` крутит сама сцена корутиной (`VnStage.Commands`). Рантайм читает
  скомпилированный `.lvn` (`LvnDocument.Parse`); `.lvns` компилирует
  студия при публикации (компилятор — Editor/сервер, не рантайм).
- **События оболочки, за которые можно зацепиться:** `NovelShell.OnTabTravel(from,to)`,
  `OnMenuVisible`, `WardrobeSheet.OnEquip/OnPeek/OnCharacterPicked`,
  `PackShopScreen.Buy`, кошелёк (`LvnWallet`), ввод на панели (`PointerDown`),
  возврат из главы (`ShowMenuScene`), ежедневная награда, уровень.
- **Композиция вкладки** живёт в `LvnMenuStage` (слот/план по признаку
  «главная / боковая»): расширяется до «комнат» без новой системы координат.

## 3. Как делают другие

- **Live2D (стандарт де-факто для «живых» героинь в лобби).** В `model3.json`
  движения сгруппированы по СОБЫТИЯМ: группа `Idle` (случайное из списка, по
  кругу, когда никто не трогает), `TapBody` / `TapHead` (по областям нажатия),
  плюс `Expressions` (`.exp3.json` с fade in/out). Интерактив — только через
  SDK: idle зацикливается, тап прерывает и возвращает в idle
  ([Live2D forum](https://community.live2d.com/discussion/308/questions-on-character-idle-motion-amp-hit-area-response),
  [пример model3.json](https://github.com/Live2D/CubismWebSamples/blob/develop/Samples/Resources/Mao/Mao.model3.json),
  [разбор файлов](https://medium.com/@vesper_illust/understanding-live2d-model-data-files-for-vtube-studio-0ada080a35b2)).
- **Ren'Py ATL** — ровно наш случай, только про картинки: таймлайн
  «`"eileen surprised"` / `pause 1.2` / `"eileen happy"` / `pause 1.3` …»,
  `repeat`, `choice` (случайный выбор с весами), `parallel`, и блоки-события
  `on show / on hide / on hover / on idle` + свои события через
  `renpy.transform_event` ([ATL](https://www.renpy.org/doc/html/transforms.html)).
- **Гача-лобби** (Azur Lane, Arknights, Blue Archive): тап → реплика/движение,
  приветствие по времени суток, реакции открываются симпатией, кулдаун
  («раз в 3 часа»), особые сцены у мебели
  ([Blue Archive Cafe](https://bluearchive.fandom.com/wiki/Cafe),
  [Azur Lane dorm](https://mobagereroll.wordpress.com/2018/11/07/azur-lane-review/)).
- **Seven Hearts Stories** (то, что Илья зовёт «7 хард сторс», Sinomi Games):
  описание в сторе про гардероб, свидания и CG; про лобби ничего
  ([App Store](https://apps.apple.com/us/app/seven-hearts-stories/id1627771736)).
  Готовых «последовательностей на вынос» ни у кого нет — это данные внутри
  приложений. Забирать можно **словарь событий и модель исполнения**, не
  сами клипы.

**Общий знаменатель индустрии:** событие → именованный клип; клип =
таймлайн смен состояния с паузами; случайный выбор; idle-цикл; возврат в
нейтральное; клипы — ДАННЫЕ, не код.

## 4. Варианты

**A. По одной фишке в C#** (таймер тут, `if (tab == Store)` там). Быстро
сегодня, а через месяц — десять таймеров, размазанных по оболочке; ровно та
история, что была с вкладками («пять перечней одного набора»). Нет.

**B. Своя мини-грамматика в манифесте** (`"purchase": "surprised 1.2, happy 1.3, sleep 2"`).
Компактно, но это ШЕСТАЯ реализация языка при четырёх-пяти живых
(`docs`, риск расхождений) — и она сразу захочет `if`, случайность,
параллельность, звук. Всё это в языке уже есть. Нет.

**C. Реакции = сцены на языке LVN.** РЕКОМЕНДУЮ. Новелла указывает в манифесте
СЦЕНАРИЙ ВИТРИНЫ — обычный `.lvns`, где метка = событие:

```
label on_store            # пока игрок в магазине
  actor mara happy
  end

label on_idle             # бездействие на главной (порог — в манифесте)
  actor mara discontent
  end

label on_purchase         # клип, потом возврат к настроению комнаты
  actor mara surprised
  wait ms=1200
  actor mara happy
  wait ms=1300
  actor mara sleep
  wait ms=2000
  end
```

Дальше — всё, что язык уже умеет, без новых операторов: `anim mara scale
[1 1.05 1] 0.4s` (подпрыгнуть), `sfx`, `if global.crystals > 100` (богатому
игроку — другая реакция), `call` общих кусочков, позже `random`
(в очереди языка). Автор пишет то же, что в главе; студия компилирует как
главу; движок играет тем же `LvnPlayer`.

Композиция комнат (слот, план) остаётся ЧИСЛАМИ витрины (`LvnMenuStage`,
перекрываются `ui.browse`): это где стоит камера, а не что делает героиня.

## 5. Модель исполнения (правила, которые надо зафиксировать)

1. **Один клип в кадре.** Событие прерывает текущий клип (как `on` в ATL:
   «handling of any other event ends»). Приоритеты: событие (покупка) >
   комната (магазин) > бездействие > нейтральное.
2. **Возврат.** Клип кончился (`end`) → играет метка комнаты, если есть
   (`on_store`), иначе нейтральное лицо (ось из каталога/гардероба).
3. **Бездействие** считается от последнего касания панели и от прихода в
   комнату; действует на главной (параметр `idle_after`, по умолчанию 10 с;
   `idle_rooms` — где считать); любое касание возвращает настроение комнаты;
   повтор не чаще кулдауна.
4. **Клип не блокирует ввод и не показывает диалог.** `say`/`choice` в
   сценарии витрины — фаза 2 (облачко над героиней); в фазе 1 — игнор с
   предупреждением в логе.
5. **Слой Menu партитуры**: всё идёт отправителем `LvnSender.Menu`, глава
   не видит ничего. Вход в главу обрывает клип; возврат в меню — событие
   `on_return`.
6. **Прогрев.** Лица, которые упоминает сценарий, греются вместе с куклой
   при старте (сканирование осей у движка есть: `VnStage.Preload`).
7. **Ничего не сохраняется** — это витрина, а не прогресс.
8. **Диагностика** `[lvn-mood]`: событие → метка → чем кончилось.

Словарь событий фазы 1: `on_home`, `on_store`, `on_wardrobe`, `on_profile`
(комнаты), `on_idle`, `on_tap` (тап по героине), `on_purchase`, `on_equip`,
`on_return` (из главы), `on_launch`. Расширяется без правок движка: оболочка
поднимает событие — если метки нет, ничего не происходит.

## 6. Что это стоит

- Движок: проигрыватель фрагмента на слое Menu (адаптер `ILvnStage` →
  `VnStage.ApplyStage(cmd, Menu)`, прыжок на метку, прерывание, «клип
  кончился»); дом настроения `LvnMenuMood` (события, приоритеты, idle,
  возврат); поле `ui.browse.reactions` (url `.lvn`) + `idle_after`.
  Стражи: чистая машина состояний без Unity.
- Оболочка: поднимать события в шести местах (вкладки, касание, покупка,
  наряд, возврат, старт); тик бездействия.
- Контент продукта: `menu.lvns` с тремя реакциями Ильи; манифест. Пока не
  опубликовано — в редакторе реакций не будет (движок эмоций по именам не
  знает, и не должен: «ноль хардкода сущностей»).
- Фаза 2: облачко реплик, время суток, симпатия как условие, кулдауны,
  `random` в языке, тап по зонам (голова/тело — как `TapHead`/`TapBody`).

## 9. Что переделано 11.09 после живой проверки

- Реакция = **выражение лица** (`LvnFace`), не команда сцене: не двигает фигуру, не записывается в облик, уступает выбору игрока в гардеробе. Настроение комнаты играет **после** переезда (`RoomMoodAfterTravel`). Касание будит со сна (`Wake`).
- Шаблон сценария и словарь лиц «что нарисовано, а не что в названии» — `howto/menu-reactions/`. Главное оттуда: `medium` — взгляд искоска, не «нейтрально»; `discontent`/`offence`/`anger` в витрине не использовать; скука кончается сном, а не хмуростью.
