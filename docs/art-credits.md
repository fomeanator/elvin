# Происхождение арта (art credits)

Репозиторий движка **публичный**, поэтому в него кладётся только арт, который
никого ни к чему не обязывает: **CC0 или public domain**. CC-BY, CC-BY-SA, GPL,
OGA-BY и любые «free, но укажите автора» — **нельзя**: обязательство рано или
поздно нарушится молча, и арт придётся выбрасывать.

Этот файл — доказательство происхождения. Если картинки нет в таблице, считай,
что её лицензия неизвестна, и не используй её.

## Как проверять лицензию на Wikimedia Commons (грабли)

Короткая сводка API («Public domain» в поле `LicenseShortName`) **врёт** в одном
частом случае: фотография картины может быть под CC-BY-SA, даже если сама
картина в public domain. Два файла пришлось выбросить именно из-за этого:

* `Smithsonian-Church-Aurora Borealis-2139 (cropped).jpg` — `{{Licensed-PD|PD-old-100-1923|Cc-by-sa-4.0}}`, то есть снимок CC-BY-SA;
* `Adolph Menzel - Das Eisenwalzwerk ... .JPG` — `{{self|cc-by-sa-4.0}}`;
* `Grand Canyon of the Yellowstone painting, by Thomas Moran (12913460813).jpg` — `{{cc-by-2.0}}` (перезалив с Flickr).

Правило: открыть страницу файла, найти раздел **Licensing** и убедиться, что там
стоит только `PD-*` / `CC0` / `Cc-zero`, а у обёрток `Licensed-PD*` **оба**
параметра — тоже `PD-*`. Если видно `cc-by`, `cc-by-sa`, `GFDL`, `self|cc-...` —
файл не берём.
