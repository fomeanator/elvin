# ТЗ на арт: Elemental Chronicles

Готовое задание для генератора картинок. Технические требования — жёсткие: движок
складывает персонажа из слоёв по имени файла, поэтому отступ от формата ломает
сборку молча (слой просто не находится и не рисуется).

Игра уже написана и играется: 6 глав, 2551 строка. Не хватает только арта.

---

## 1. Технические требования (нарушать нельзя)

### Персонажи

| Параметр | Значение |
|---|---|
| Размер | **700 × 1400 px**, ровно |
| Формат | **PNG, RGBA, прозрачный фон** |
| Кадрирование | фигура в полный рост, **ступни на самом низу холста**, над головой 3–5% воздуха |
| Поза | строго фронтально, по центру холста, взгляд в камеру |
| Освещение | ровное, без сильных теней на землю (тень рисует движок) |
| Текст | **никакого текста, подписей, водяных знаков** |

Каждый персонаж — это **два слоя на одном холсте**, которые накладываются друг
на друга без сдвига:

```
<id>/body_stand.png     тело, спокойная стойка, руки опущены
<id>/body_raised.png    то же тело, одна рука поднята (жест, указание)
<id>/face_calm.png      только ГОЛОВА, спокойная
<id>/face_angry.png     только ГОЛОВА, злая/напряжённая
<id>/face_smile.png     только ГОЛОВА, улыбка/усмешка
```

**Главное про слои.** `body_*` рисуется БЕЗ ГОЛОВЫ (или с нейтральной болванкой,
которую полностью закроет лицо). `face_*` — прозрачный холст 700×1400, на котором
голова нарисована **ровно в том месте, где она была бы на теле**. Проверка:
положил `face_calm.png` поверх `body_stand.png` — шея сошлась, ничего не
сдвинулось. Голова обязана оставаться на одном месте во всех трёх `face_*` и в
обеих позах `body_*`, иначе персонаж будет дёргать головой при смене эмоции.

### Фоны

| Параметр | Значение |
|---|---|
| Размер | **1920 × 1080 px** |
| Формат | **JPG**, без прозрачности |
| Композиция | середина кадра свободна: снизу по центру стоят персонажи, снизу лежит окно диалога (~25% высоты) |
| Текст | никакого |

### Предметы (`obj`)

Те же правила, что у персонажей: PNG RGBA, прозрачный фон. Размер по смыслу
предмета, но не больше 700 × 700.

## 2. Персонажи, которых не хватает

Уже нарисованы (менять не нужно): `ec_niharis`, `ec_druid`, `ec_techno`.
Ниже — те, кого игра выводит на сцену, а арта нет. Описания и цитаты взяты из
самого текста игры, чтобы облик совпал с голосом.

### `ec_skeleton` — **Кнопка**
Маленький нелепый робот, который прицепился к герою и не отстаёт. Говорит
короткими фразами, гордится единственной своей кнопкой.

> «Я — Кнопка. У меня есть кнопка. Значит, я Кнопка. Логично.»
> «Не отстану. Я лёгкий.»

Облик: ростом заметно ниже человека (займи 40–50% высоты холста, ступни всё равно
внизу), корпус — простая жестяная коробка, на груди ОДНА большая круглая кнопка,
тонкие ножки-палки, огромные наивные глаза-лампы. Не страшный, обаятельный,
слегка помятый. Эмоции читаются глазами и наклоном «брови»-пластины.

### `ec_necromancer` — **Костолом**
Скелет-бюрократ из «отдела учёта поднятого имущества». Вежливый, всё делает по
форме, никого не поднимает без бумаги. Комический, а не жуткий.

> «Добрый день. Костолом, отдел учёта поднятого имущества. Не пугайтесь.»
> «Форма Н-13, графа „происхождение“. Написано — поднят мною, в четверг.»

Облик: скелет в опрятном сюртуке конторщика, круглые очки на носовой кости, под
рукой папка с бумагами, к поясу подвязана чернильница. Аккуратный, чуть
сутулый. `angry` — не ярость, а раздражение неправильно заполненной формой.

### `ec_spirit` — **Отражение**
Двойник героя: он же, но ничего не забывший. Говорит спокойно и неприятно точно.

> «Я — это ты. Разница одна. Я ничего не забыл.»
> «Ты дошёл сюда, не решив ничего. Так тоже можно. Пусто, но можно.»

Облик: силуэт человека, собранный из зеркальных осколков и холодного света,
черты угадываются, но лицо не дописано — как отражение в разбитом стекле.
Полупрозрачность допустима (альфа), контур должен читаться на тёмном фоне.

### `ec_cyberguard` — **Ржавый**
Древний робот-охранник на четырёх процентах заряда. Разобрал себя, чтобы
почистить контакты, и не смог собрать обратно.

> «Пи. Заряд четыре процента. Здравствуйте. Пи.»
> «Я разобрался, чтобы почистить контакты. Это была ошибка планирования.»

Облик: крупный, тяжёлый, ржавый; одна рука висит на проводах, часть панелей
снята и стоит рядом, из корпуса торчат жгуты. На груди — индикатор заряда,
почти пустой. Движется медленно; в позе `raised` рука поднята с усилием.

### `ec_tyrant` — **Звёздный тиран**
Финальный противник. Не злодей-крикун, а равнодушная космическая инстанция,
которая «устраняет занятость» планет.

> «Опись. Планета. Одна. Занята. Устраняю занятость.»
> «Опись продолжается. Объект — спутник. Занят.»

Облик: огромная фигура из чёрного камня и звёздного света, вместо лица — плита с
геометрическим знаком, за спиной обломки орбит. Должен читаться как нечто
несоизмеримо большее человека: заполни холст плотно, кадрируй по грудь, если в
полный рост не влезает величина.

### `ec_hero` — **главный герой (НУЖЕН, сейчас его нет вовсе)**
Игрок вводит своё имя в начале, поэтому лицо должно быть достаточно нейтральным,
чтобы подошло любому. Персонаж просыпается в чужом мире с чужим мечом в руке.

Облик: подросток в простой дорожной одежде, поверх — куртка не по размеру, за
спиной пустой ранец, в руке короткий меч, который ему явно велик. Никаких
опознавательных знаков фракций: герой выбирает сторону по ходу игры.
**Дополнительно нужны две пары поз** (тот же холст, та же голова):

```
ec_hero/body_stand.png     стоит, меч опущен
ec_hero/body_raised.png    меч поднят, замах
ec_hero/face_calm.png
ec_hero/face_angry.png
ec_hero/face_smile.png
```

`shining_zone`. Игра идёт шесть глав, а меняется всего четыре вида — сцены

## 5. Единый стиль

- Плоские цвета, чёткий силуэт, минимум мелкой детализации — игру смотрят на
  телефоне, мелочь всё равно пропадёт.
- Мир: два лагеря. **Эфирия** — живое, растительное, тёплые зелёные и золотые.
  **Техногард** — металл и протезы, холодные синие и стальные.
- Персонажи узнаются по силуэту и одному яркому пятну цвета (у Нихарис — красный
  `#c8465a`, у Техника — голубой `#5ec8dc`, у Друида — зелёный).
- Тон — не мрачное фэнтези: игру придумали дети 9 и 12 лет, и в ней много
  смешного (робот с одной кнопкой, скелет-бюрократ). Пусть будет приключение, а
  не хоррор.

## 6. Как проверить, что арт подошёл

1. Все файлы персонажа лежат в `/content/sprites/<id>/` с именами точно как выше.
2. `body_*` и `face_*` одного персонажа — 700×1400, и голова совпадает при
   наложении.
3. Фоны 1920×1080, середина кадра не занята важным.
4. Ни на одной картинке нет текста.

После этого арт кладётся на сервер, персонаж дописывается в `manifest.json` в
блок `sprites` по образцу:

```json
"ec_hero": {
  "name": "Герой",
  "color": "#e8c07a",
  "layers": [
    { "url": "/content/sprites/ec_hero/body_{pose}.png" },
    { "url": "/content/sprites/ec_hero/face_{emotion}.png" }
  ],
  "defaults": { "pose": "stand", "emotion": "calm" },
  "axes": {
    "pose": ["stand", "raised"],
    "emotion": ["calm", "angry", "smile"]
  }
}
```
