# Механики Elemental Chronicles — шпаргалка

Всё, что уже работает в игре, и как этим пользоваться. Сюжет пишешь ты, механики
готовы: бой, уровни, здоровье, стихии, кристаллы, проверки, репутация, концовки.

Каждый пример из этого файла **проверен компиляцией**: 13 примеров, у каждого
«0 warning(s)». Два примера из раздела про бой — это целые работающие главы, их
не только компилировали, но и проиграли до конца (и с победой, и с проигрышем).
Копируй и меняй под свою сцену.

Первая строка любой главы:

```
scene моя_глава
include "ec-mechanics.lvns"
```

После этого доступно всё, что ниже. Если забыл имя — ищи в
`server/content/scripts/ec-mechanics.lvns`, там всё разложено по разделам.

---

## Что помнит игра

Это переменные. Их можно менять как обычно: `здоровье = 10`.

| Переменная | Что это |
|---|---|
| `имя` | имя героя, игрок вводит его в начале |
| `опыт` | копится; **уровень не хранится, а считается** из опыта — `lvl()` |
| `здоровье` | текущее; потолок — `maxhp()`, растёт с уровнем |
| `мощь` | сила удара от оружия и тренировок |
| `броня` | вычитается из урона врага |
| `стихии` | список выученных стихий |
| `сумка` | инвентарь кристаллов: стихия → сколько |
| `эфирия`, `техногард` | репутация у двух фракций |
| `репутация` | общая слава |
| `ходы` | время меряется ходами: реального таймера в движке нет |
| `союзники` | кто идёт с тобой; влияет на финал |
| `память` | «гл2» → решение главы одной строкой |

## Бой

Формула уже посчитана за тебя. Ты только описываешь, что происходит.

```
«Перед тобой матёрый скелет.»
- Ударить огнём {
  «Урон {hit("огонь", "матёрый скелет")}, ходов нужно {rounds("огонь", "матёрый скелет")}.»
  здоровье = hurt(toll("огонь", "матёрый скелет"))
  опыт = опыт + reward("матёрый скелет")
  сумка = addgem(drop("матёрый скелет"), 1)
  победы = победы + 1
}
- Сначала прикинуть {
  «Шансы: {odds("огонь", "матёрый скелет")}. Ты выстоишь {endure("матёрый скелет")} ходов.»
}
«Здоровье {здоровье} из {maxhp()}, это {hppct()} процентов.»
```

| Функция | Что отвечает |
|---|---|
| `hit(стихия, враг)` | сколько урона ты наносишь за удар |
| `rounds(стихия, враг)` | за сколько ходов убьёшь |
| `endure(враг)` | сколько ходов ты сам выстоишь |
| `beats(стихия, враг)` | победишь ли вообще (да/нет) |
| `toll(стихия, враг)` | сколько здоровья будет стоить победа |
| `odds(стихия, враг)` | словами: безнадёжно / рискованно / ровно / уверенно / легко |
| `reward(враг)` | сколько опыта дадут |
| `drop(враг)` | кристалл какой стихии упадёт |
| `advantage(a, b)` | процент урона стихии `a` против стихии `b` |

**Кого можно поставить врагом** (готовые таблицы здоровья, стихии и урона):
скелет, матёрый скелет, некромант, кристальный паук, песчаный червь, ледяной
великан, дрон, глитч, страж огня, страж воды, страж земли, страж ветра, звёздный
тиран, меха-полковник, Нихарис, Костолом, Ржавый.

Хочешь своего врага — допиши три строки в `ec-mechanics.lvns`:

```
враг_хп = put(враг_хп, "болотный тролль", 40)
враг_стихия = put(враг_стихия, "болотный тролль", "земля")
враг_урон = put(враг_урон, "болотный тролль", 6)
```

Всё остальное — урон, шансы, награда — посчитается само. **Это главное правило
этих механик: новый враг, стихия или цена — одна строка в таблицу, а не новый код.**

Это быстрый бой — одна проверка и одна реплика. Если нужна настоящая схватка,
где игрок каждый ход выбирает, куда бить и что закрывать, — следующий раздел,
и там к трём строкам чисел добавляется четвёртая, с расписанием врага.

## Бой ход за ходом — три зоны и паттерн врага

Первый способ драться (выше) — это одна проверка: хватило урона или нет.
Этот способ — настоящая схватка один на один на 4–6 ходов, и в ней важно не
«хватит ли урона», а **читаешь ли ты противника**.

Как это выглядит для игрока. Каждый ход он выбирает **два раза**: сначала куда
бьёт (голова / корпус / ноги), потом что закрывает (голова / корпус / ноги).
Враг ходит **не случайно** — у него своё расписание, оно называется **паттерн**,
и перед твоим выбором он его выдаёт короткой фразой. Эта фраза называется
**тычок**. Прочитал тычок — угадал ход. Запомнил расписание — победил. Кубиков
в бою нет вообще: `rand()` внутри боя не встречается ни разу, и это правило,
а не случайность.

Живёт всё это отдельным файлом `ec-battle.lvns`.

### Шаг 1. Вставить бой в свою главу

Копируй целиком, потом меняй имена и текст. Это работающая глава:

```
scene моя_глава
include "ec-battle.lvns"

hudon
desert

«Из дрожащего воздуха выходит скелет в костюме, с папкой под мышкой.»
Костолом: Добрый день. Костолом, отдел учёта поднятого имущества.

battle("Костолом", 5)

if бой_победа == 0 -> проиграл
-> победил

:победил
«Форма Н-13 остаётся лежать на песке, придавленная камнем. Претензию тебе так и не вручили.»
-> дальше

:проиграл
«Он ставит печать тебе на плечо, аккуратно, чтобы не смазать.»
-> дальше

:дальше
«Дальше по главе.»
-> __end
```

Что здесь обязательно:

- `include "ec-battle.lvns"` — второй строкой. Механики он подтянет сам,
  отдельный `include "ec-mechanics.lvns"` не нужен (но и не мешает — подключить
  дважды безопасно).
- `battle("имя врага", сколько ходов)` — это и есть весь бой, одна строка.
  Ходы зажаты в 4–6: напишешь 99 — будет 6, напишешь 1 — будет 4.
- **Две строки после боя.** `бой_победа` равна 1 или 0, и глава сама решает,
  куда идти. Иначе — никак: прыгнуть на метку, имя которой лежит в переменной,
  движок не умеет.

Что здесь твоё: фон (`desert`), полоска (`hudon`), имена меток и весь текст.
Фон и полоску бой не трогает — у него своя полоска, строкой ниже.

### Что игрок видит на экране

Настоящий кусок схватки с Костоломом, слово в слово из игры:

```text
Против тебя Костолом — 20 здоровья, стихия тьма. В руке у тебя огонь, и это 100 процентов урона по нему.
Костолом держит папку у груди и постукивает пальцем по верхней графе.
   > Бить в голову / Бить в корпус / Бить в ноги
Что закрываешь?
   > Закрыть голову / Закрыть корпус / Закрыть ноги
Ты бьёшь в голову — прошло, минус 5. Голова у него мотнулась — следующий ход он потеряет. Ты закрыл голову — его удар ушёл в защиту.
Противник ещё не пришёл в себя после удара по голове. Стоит открытый и не бьёт.
```

Вторая строка — тычок, он показывается **вместе с опциями**, лишнего клика нет.
«Постукивает по верхней графе» значит, что ударит по голове — голову и надо
закрыть. «Папка у груди» значит, что корпус он закрывает — бить туда бесполезно.
Костолом всю схватку идёт по форме сверху вниз (голова, корпус, ноги) и папку от
груди не убирает никогда. Его расписание выучивается за один бой — в этом вся
затея.

### Правила, которые уже посчитаны за тебя

| Что | Как работает |
|---|---|
| твой удар | прошёл, если твоя зона **не совпала** с той, что враг закрывает этот ход |
| его удар | прошёл, если его зона **не совпала** с твоей защитой |
| оба сразу | считаются в одном ходу: могут попасть оба, один или ни один |
| попали оба | голова бьёт ноги, ноги бьют корпус, корпус бьёт голову. Кто выиграл в этой тройке — бьёт на +50 %, кто проиграл — на −30 % |
| **голова** | оглушение: следующий ход пропущен. Второй раз подряд оглушить нельзя, иначе бей в голову каждый ход — и противник больше не ходит вообще |
| **ноги** | убежать больше не получится, и уклонение теряется |
| **корпус** | самый большой обычный урон, никакого эффекта |
| и по врагу, и по тебе | эффекты зон работают в обе стороны |
| стихия | бой сам берёт лучшую из выученных против этого врага (нет ни одной — «кулак»), чтобы выборов осталось два, а не три |
| длина | 4–6 ходов. Никто не упал за лимит — дистанцию разрывает тот, кому хуже |

### Шаг 2. Свой враг: три строки чисел и одна строка паттерна

Это главное, для чего бой так устроен. Врага можно завести **прямо в своей
главе**, сразу после `include`. Ниже — целая работающая глава, копируй и меняй:

```
scene глава_с_троллем
include "ec-battle.lvns"

// Три строки чисел: сколько здоровья, какая стихия, сколько бьёт за раз.
враг_хп = put(враг_хп, "болотный тролль", 24)
враг_стихия = put(враг_стихия, "болотный тролль", "земля")
враг_урон = put(враг_урон, "болотный тролль", 5)

// Одна строка паттерна. ПИШЕТСЯ В ОДНУ СТРОКУ, какой бы длинной она ни вышла.
паттерн = put(паттерн, "болотный тролль", list(list("корпус", "ноги", "Тролль набирает воздух и наклоняется к твоей груди. Лапы он подобрал под себя."), list("голова", "", "Он поднимает обе лапы над твоей головой. Брюхо открыто целиком, и удар будет тяжёлый.", 150)))

geysers
«Болото пахнет так, что щиплет глаза. Из воды поднимается тролль.»

battle("болотный тролль", 5)
if бой_победа == 0 -> тролль_победил
-> тролль_упал

:тролль_упал
«Тролль уходит под воду. Пузыри идут ещё минуту, потом перестают.»
-> дальше

:тролль_победил
«Ты отходишь по колено в тине. Тролль не преследует — ему и так хорошо.»
-> дальше

:дальше
«Дальше по главе.»
-> __end
```

Из чего сделан **один шаг** паттерна:

```text
list("корпус", "ноги", "Тролль наклоняется к твоей груди. Лапы подобрал.", 150)
      ^^^^^^^   ^^^^^   ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^  ^^^
      куда      что     тычок: что игрок читает ПЕРЕД своим выбором        сила
      бьёт      закр.                                                      в %
```

- `""` в первом поле — этот ход враг **не бьёт**: замах, подзарядка, ушёл в песок.
- `""` во втором — он **не закрывается вовсе**. Это окно: бей куда хочешь.
- Четвёртое поле можно не писать, тогда сила 100. 150 — удар в полтора раза,
  200 — вдвое.
- Шагов: **2** у мелочи, **3** у середняка, **4** у босса. Кончились — паттерн
  начинается с первого.

Ещё две необязательные строчки, если враг особенный (обе лежат в
`ec-mechanics.lvns`, раздел 2.4a, и обе БЕЗ кубика):

```
враг_трус = put(враг_трус, "болотный тролль", 0)     // 0 — стоит насмерть
враг_уклон = put(враг_уклон, "болотный тролль", 20)  // 20 % удара в корпус уходит вскользь
```

По умолчанию трусость 40: враг разрывает дистанцию, когда здоровья у него
осталось меньше 40 процентов, и это считается твоей победой (`бой_итог` будет
`прогнал`). Поставишь 0 — будет стоять до конца. А **подрубленные ноги побег
отменяют**: в этом и смысл зоны «ноги».

Как это играется у тролля:

| ход | что читает игрок | бьёт | закрывает | что делать |
|---|---|---|---|---|
| 1 | «наклоняется к твоей груди, лапы подобрал под себя» | корпус | ноги | закрыть корпус, бить в голову или корпус |
| 2 | «поднимает лапы над головой, брюхо открыто» | голова, 150 % | ничего | закрыть голову, бить куда угодно — блока нет |
| 3 | снова первый тычок | корпус | ноги | паттерн пошёл по кругу |

Если враг нужен **во всех главах**, те же четыре строки положи в общие файлы:
три строки чисел — в `ec-mechanics.lvns` (раздел 2.4), строку паттерна — в
`ec-battle.lvns` (раздел 2). Тогда его не надо переписывать в каждой главе.

### Как придумать паттерн, который интересно разгадывать

1. **Паттерн — это характер.** Костолом бюрократ, поэтому бьёт строго по форме
   сверху вниз и никогда не убирает папку от груди. Ржавый — робот на четырёх
   процентах заряда, поэтому бьёт через ход, а в ход подзарядки не закрывается
   вообще. Звёздному тирану всё равно, поэтому он замахивается два хода, в
   замахе открыт весь, зато бьёт вдвое. Сначала придумай, **кто** это, потом
   расписание.
2. **Тычок обязан говорить правду.** Стоит в шаге «голова» — в тычке должны
   быть голова, лицо, лоб, замах сверху. Проверка простая: прочитай тычок вслух
   и спроси себя, куда он ударит и что закрыл. Не ответил — перепиши тычок.
   Без честного тычка первый бой с новым врагом это угадывание, а не игра.
3. **Хочешь дать игроку шанс — открой зону.** `""` в защите плюс сила 150–200:
   враг раскрылся, но если не угадаешь, получишь вдвое. Это самый интересный
   шаг в любом паттерне, у боссов он есть почти всегда.
4. **Не копируй чужое расписание со сдвигом.** «корпус-голова-ноги» и
   «голова-ноги-корпус» — это ОДИН И ТОТ ЖЕ враг, просто начал с другого хода:
   после первого хода их не отличить. Меняй не начало, а порядок.
5. **Никакого `rand()`.** Со случайным врагом защита превращается в угадывание
   один к трём, и осваивать нечего. Расписание — это то, что игрок выучивает.
6. **Не делай один список из девяти пунктов** («голова-голова», «голова-корпус»
   и так далее). Два выбора по три — два простых вопроса; девять комбинаций —
   каша, в которой не видно ни зон, ни характера.

### Шаг 3. Что бой отдаёт обратно в главу

| Переменная | Что в ней |
|---|---|
| `бой_победа` | 1 или 0 — по нему и ветвись |
| `бой_итог` | `убил` · `прогнал` (сбежал сам) · `выстоял` (ходы кончились, ему хуже) · `отступил` (ходы кончились, хуже тебе) · `пал` |
| `бой_ноги_мои` | 1 — тебе перебили ноги, уйти ты не можешь. Готовая ветка плена |
| `бой_ноги_врага` | 1 — перебиты ему, он никуда не убежал |
| `бой_ход`, `бой_хп`, `бой_стихия` | сколько ходов заняло, сколько у него осталось, чем ты дрался |

**Разные проигрыши** — ноги решают, дадут ли тебе уйти:

```
battle("Костолом", 5)
if бой_победа == 1 -> отбился
if бой_ноги_мои == 1 -> плен
-> уполз
```

**Боссы.** За 4–6 ходов босса с сотней здоровья не убить, и не надо. Ходы
кончились, а он ещё стоит: `бой_итог == "выстоял"` значит «он отступил живым» —
и продолжение пишется именно так, а не «ты его добил»:

```
бой_фора = урон_тирану
battle("звёздный тиран", 6)
if бой_итог == "выстоял" -> тиран_ушёл_но_вернётся
if бой_победа == 0 -> тиран_взял_планету
-> тиран_рассыпался
```

`бой_фора` перед вызовом вычитается из здоровья врага — так работает сюжетный
урон, нанесённый до схватки (`урон_тирану`). После боя она сама сбрасывается.

Опыт, кристалл, счётчики побед и поражений и уровень бой начисляет **сам**.
Второй раз начислять не надо — награда удвоится. Проигрыш — **не загрузка
сейва**, а поворот сюжета: бой возвращается в главу, и глава идёт другой веткой.

### Пять ошибок, на которых спотыкаются все

1. **Паттерн в две строки.** Строка получается длинной, и рука сама переносит
   её. Так нельзя, и компилятор об этом НЕ предупредит: он оборвёт выражение,
   а хвост покажет игроку как реплику. Вот что игрок прочитает вслух:
   `list("корпус", "ноги", "Тролль оседает на лапы.")))`. Одна строка — и всё.
2. **Двойные кавычки внутри тычка.** `"Он говорит "сейчас в грудь" и смотрит"`
   — и всё. Компилятор скажет «0 warning(s)», а в игре сломается **вся таблица
   паттернов**: твой враг и все остальные будут драться по скучному расписанию
   из двух шагов, и никто тебе об этом не сообщит. Внутренняя цитата — только
   «ёлочками» или „лапками“, они внутри тычка совершенно безопасны (проверено).
3. **Двоеточие в СВОЕЙ строке текста.** В тычке двоеточие безопасно, а вот
   `«Он смотрит на тебя: сейчас ударит.»` в главе превратится в реплику
   персонажа по имени «Он смотрит на тебя». Валидатор молчит. Пиши тире.
4. **Имя врага написано по-разному** в четырёх строках («болотный тролль» и
   «Болотный тролль»). Предупреждения не будет: бой возьмёт числа по умолчанию
   (10 здоровья, «земля», 3 урона) и чужой паттерн. Проверь, что все четыре
   строки написаны буква в букву одинаково.
5. **Забыл `->` перед меткой,** в которую можно и прыгнуть, и «свалиться»
   сверху. Игрок попадёт туда, куда не собирался, а компилятор предупредит —
   поэтому цель всегда «0 warning(s)».

## Уровень и здоровье

```
if опыт >= nextxp() -> повышение
-> дальше

:повышение
levelup
«Теперь ты {lvl()} уровня — {title()}. До потолка {maxlvl()}.»
-> дальше

:дальше
```

`lvl()` уровень · `title()` звание · `maxlvl()` потолок · `nextxp()` сколько опыта
до следующего (0 = потолок взят) · `maxed()` потолок взят? · `maxhp()` предел
здоровья · `alive()` живой? · `hurt(n)` / `heal(n)` — **присваивай результат**:
`здоровье = hurt(5)` · `hppct()` процент здоровья.

## Стихии

```
стихии = learn("огонь")
стихии = learn("земля")
if canfuse("огонь", "земля") -> сплав
-> дальше

:сплав
«Огонь и земля дают {fuse("огонь", "земля")}.»
-> дальше
```

`learn(e)` выучить · `knows(e)` знает? · `elpow(e)` сила стихии ·
`fuse(a,b)` что даёт сочетание · `canfuse(a,b)` сочетаются ли.

Сочетания и силы лежат таблицами `рецепты` и `сила` — добавляй строкой.

## Кристаллы и покупки

```
сумка = addgem("огонь", 5)
- Купить щит -> куплено expr="afford(\"огонь\", \"щит\")"
- Пройти мимо -> дальше

:куплено
сумка = usegem("огонь", price("щит"))
броня = броня + 1
«Осталось {gems("огонь")} кристаллов огня, всего {gemsall()}.»
-> дальше
```

`gems(e)` сколько есть · `gemsall()` всего · `addgem(e,n)` / `usegem(e,n)` —
присваивай в `сумка` · `price(что)` цена · `afford(e, что)` хватает ли.

**Важно:** `expr=` на опции только СКРЫВАЕТ её, если не хватает. Списывать
кристаллы надо самому — `usegem`. Движок за тебя не спишет.

## Проверки «получилось или нет»

```
if roll(lvl(), normal()) -> удача
-> неудача

:удача
«Получилось. Запас над порогом: {edge(lvl(), normal())}.»
```

Сложности: `easy()`, `normal()`, `hard()`, `brutal()`.
`roll(ставка, сложность)` — прошло? · `edge(ставка, сложность)` — на сколько
прошёл или не дотянул · `score(s)` — итоговая ставка.

Ставкой может быть что угодно: `lvl()`, `доверие`, `len(союзники)`, `мощь`.

## Фракции и концовки

```
эфирия = эфирия + 3
техногард = техногард + 1
«Ты за {ally()}. Ранг {rank(репутация)}. Перекос {rift()}, единство {unity()}.»
if эфирия >= goal("лес") -> финал_лес
-> финал_обычный
```

`ally()` за кого ты (Эфирия / Техногард / Равновесие) · `rank(r)` звание по
репутации · `unity()` минимум из двух репутаций — «истинное единство» ·
`rift()` насколько перекосило · `goal(имя)` порог концовки из таблицы `финалы`.

## Три правила, чтобы не мучиться

1. **Всегда `include "ec-mechanics.lvns"`** второй строкой. Без него нет ни
   одной функции.
2. **Цель — ноль предупреждений.** Компилируй и смотри: каждое предупреждение
   это настоящая поломка (ветка ведёт в никуда, глава кончается молча). Ноль —
   значит игру можно проходить.
3. **Ставь `->` перед меткой,** в которую можно и прыгнуть, и «свалиться»
   сверху. Иначе игрок попадёт туда, куда не собирался, и никакой ошибки не
   будет.

Функции добавлять можно, но помни: **имена функций и пресетов только латиницей**,
а переменные можно по-русски.
