# Механики Elemental Chronicles — шпаргалка

Всё, что уже работает в игре, и как этим пользоваться. Сюжет пишешь ты, механики
готовы: бой, уровни, здоровье, стихии, кристаллы, проверки, репутация, концовки.

Каждый пример из этого файла **проверен компиляцией** — 276 команд, ноль
предупреждений. Копируй и меняй под свою сцену.

Первая строка любой главы:

```
scene моя_глава
include "ec-mechanics.lvns"
```

После этого доступно всё, что ниже. Если забыл имя — ищи в
`server/content/scripts/ec-mechanics.lvns`, там всё разложено по разделам.

---

## Что помнит игра

Это переменные. Их можно менять как обычно: `здоровье = 10`.

| Переменная | Что это |
|---|---|
| `имя` | имя героя, игрок вводит его в начале |
| `опыт` | копится; **уровень не хранится, а считается** из опыта — `lvl()` |
| `здоровье` | текущее; потолок — `maxhp()`, растёт с уровнем |
| `мощь` | сила удара от оружия и тренировок |
| `броня` | вычитается из урона врага |
| `стихии` | список выученных стихий |
| `сумка` | инвентарь кристаллов: стихия → сколько |
| `эфирия`, `техногард` | репутация у двух фракций |
| `репутация` | общая слава |
| `ходы` | время меряется ходами: реального таймера в движке нет |
| `союзники` | кто идёт с тобой; влияет на финал |
| `память` | «гл2» → решение главы одной строкой |

## Бой

Формула уже посчитана за тебя. Ты только описываешь, что происходит.

```
«Перед тобой матёрый скелет.»
- Ударить огнём {
  «Урон {hit("огонь", "матёрый скелет")}, ходов нужно {rounds("огонь", "матёрый скелет")}.»
  здоровье = hurt(toll("огонь", "матёрый скелет"))
  опыт = опыт + reward("матёрый скелет")
  сумка = addgem(drop("матёрый скелет"), 1)
  победы = победы + 1
}
- Сначала прикинуть {
  «Шансы: {odds("огонь", "матёрый скелет")}. Ты выстоишь {endure("матёрый скелет")} ходов.»
}
«Здоровье {здоровье} из {maxhp()}, это {hppct()} процентов.»
```

| Функция | Что отвечает |
|---|---|
| `hit(стихия, враг)` | сколько урона ты наносишь за удар |
| `rounds(стихия, враг)` | за сколько ходов убьёшь |
| `endure(враг)` | сколько ходов ты сам выстоишь |
| `beats(стихия, враг)` | победишь ли вообще (да/нет) |
| `toll(стихия, враг)` | сколько здоровья будет стоить победа |
| `odds(стихия, враг)` | словами: безнадёжно / рискованно / ровно / уверенно / легко |
| `reward(враг)` | сколько опыта дадут |
| `drop(враг)` | кристалл какой стихии упадёт |
| `advantage(a, b)` | процент урона стихии `a` против стихии `b` |

**Кого можно поставить врагом** (готовые таблицы здоровья, стихии и урона):
скелет, матёрый скелет, некромант, кристальный паук, песчаный червь, ледяной
великан, дрон, глитч, страж огня, страж воды, страж земли, страж ветра, звёздный
тиран.

Хочешь своего врага — допиши три строки в `ec-mechanics.lvns`:

```
враг_хп = put(враг_хп, "болотный тролль", 40)
враг_стихия = put(враг_стихия, "болотный тролль", "земля")
враг_урон = put(враг_урон, "болотный тролль", 6)
```

Всё остальное — урон, шансы, награда — посчитается само. **Это главное правило
этих механик: новый враг, стихия или цена — одна строка в таблицу, а не новый код.**

## Уровень и здоровье

```
if опыт >= nextxp() -> повышение
-> дальше

:повышение
levelup
«Теперь ты {lvl()} уровня — {title()}. До потолка {maxlvl()}.»
-> дальше

:дальше
```

`lvl()` уровень · `title()` звание · `maxlvl()` потолок · `nextxp()` сколько опыта
до следующего (0 = потолок взят) · `maxed()` потолок взят? · `maxhp()` предел
здоровья · `alive()` живой? · `hurt(n)` / `heal(n)` — **присваивай результат**:
`здоровье = hurt(5)` · `hppct()` процент здоровья.

## Стихии

```
стихии = learn("огонь")
стихии = learn("земля")
if canfuse("огонь", "земля") -> сплав
-> дальше

:сплав
«Огонь и земля дают {fuse("огонь", "земля")}.»
-> дальше
```

`learn(e)` выучить · `knows(e)` знает? · `elpow(e)` сила стихии ·
`fuse(a,b)` что даёт сочетание · `canfuse(a,b)` сочетаются ли.

Сочетания и силы лежат таблицами `рецепты` и `сила` — добавляй строкой.

## Кристаллы и покупки

```
сумка = addgem("огонь", 5)
- Купить щит -> куплено expr="afford(\"огонь\", \"щит\")"
- Пройти мимо -> дальше

:куплено
сумка = usegem("огонь", price("щит"))
броня = броня + 1
«Осталось {gems("огонь")} кристаллов огня, всего {gemsall()}.»
-> дальше
```

`gems(e)` сколько есть · `gemsall()` всего · `addgem(e,n)` / `usegem(e,n)` —
присваивай в `сумка` · `price(что)` цена · `afford(e, что)` хватает ли.

**Важно:** `expr=` на опции только СКРЫВАЕТ её, если не хватает. Списывать
кристаллы надо самому — `usegem`. Движок за тебя не спишет.

## Проверки «получилось или нет»

```
if roll(lvl(), normal()) -> удача
-> неудача

:удача
«Получилось. Запас над порогом: {edge(lvl(), normal())}.»
```

Сложности: `easy()`, `normal()`, `hard()`, `brutal()`.
`roll(ставка, сложность)` — прошло? · `edge(ставка, сложность)` — на сколько
прошёл или не дотянул · `score(s)` — итоговая ставка.

Ставкой может быть что угодно: `lvl()`, `доверие`, `len(союзники)`, `мощь`.

## Фракции и концовки

```
эфирия = эфирия + 3
техногард = техногард + 1
«Ты за {ally()}. Ранг {rank(репутация)}. Перекос {rift()}, единство {unity()}.»
if эфирия >= goal("лес") -> финал_лес
-> финал_обычный
```

`ally()` за кого ты (Эфирия / Техногард / Равновесие) · `rank(r)` звание по
репутации · `unity()` минимум из двух репутаций — «истинное единство» ·
`rift()` насколько перекосило · `goal(имя)` порог концовки из таблицы `финалы`.

## Готовые постановочные сокращения

Вместо длинных команд — одно слово:

**Персонажи:** `niharis`, `druid`, `techno`, `skeleton`, `necro`, `spirit`,
`tyrant`, `cyber`. Пишешь `niharis smile` — она появляется по центру и улыбается.
`niharis hide` — уходит.

**Фоны:** `village`, `efiria`, `technogard`, `shining`, `moon`, `abyss`, `taiga`,
`arctic`, `desert`, `geysers`, `glasswaste`, `deadcity`, `catacombs`,
`spiritforest`, `firetemple`.

**Эффекты:** `dark` / `light` (затемнение), `boom` (тряска), `zoomin` / `zoomout`,
`blink`, `hurtfx` (красная вспышка), `winfx` (золотая), `snowon` / `snowoff`,
`rainon` / `rainoff`.

**Прочее:** `hudon` — показать полоску состояния, `hudoff` — скрыть,
`levelup` — всплывашка о новом уровне, `rest` — полностью вылечиться,
`tick` — прибавить ход, `clear` — убрать со сцены всех.

## Три правила, чтобы не мучиться

1. **Всегда `include "ec-mechanics.lvns"`** второй строкой. Без него нет ни
   одной функции.
2. **Цель — ноль предупреждений.** Компилируй и смотри: каждое предупреждение
   это настоящая поломка (ветка ведёт в никуда, глава кончается молча). Ноль —
   значит игру можно проходить.
3. **Ставь `->` перед меткой,** в которую можно и прыгнуть, и «свалиться»
   сверху. Иначе игрок попадёт туда, куда не собирался, и никакой ошибки не
   будет.

Функции добавлять можно, но помни: **имена функций и пресетов только латиницей**,
а переменные можно по-русски.
