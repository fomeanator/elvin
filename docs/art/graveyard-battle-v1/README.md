# «Битва на кладбище» — пакет 1

Первый пакет по приоритету из заказа ассетов: основная земля и четыре разных
силуэта надгробий. Пакет подготовлен отдельно от серверного content и пока не
подключён к сцене.

## Текстура

Материал: `земля_утоптанная`, сторона тайла — **1.5 м**.

Игровые карты:

- `textures/земля_утоптанная.png` — итоговый albedo, 1024×1024, sRGB;
- `textures/земля_утоптанная-n.jpg` — tangent-space normal;
- `textures/земля_утоптанная-h.jpg` — height, linear;
- `textures/земля_утоптанная-r.jpg` — roughness, linear.

`земля_утоптанная.jpg` — промежуточный albedo от `texture-prep.py`; для игры
следует брать PNG, откалиброванный по контракту заказа.

Результат измерений итогового albedo:

```text
p5=0.045  p50=0.220  p95=0.470
стык=21.7/22.2  обычная соседняя разница=17.7  → бесшовно
```

Карты, построенные `texture-prep.py`:

```text
height: стык=14.9/15.7 при обычной=17.3 → бесшовно
normal: стык=24.9/26.2 при обычной=26.1 → бесшовно
```

Следы обуви удалены. На вытоптанной полосе оставлены три старых следа
раздвоенных копыт. На больших площадях повтор тайла следует ломать второй
вариацией или макромаской.

## Модели

Все файлы — текстовые OBJ только с `v`, `vt`, `vn`, `f`; размеры в метрах,
Y вверх, лицевая сторона к +Z, основание на `y=0`, начало координат в центре
следа. Грани треугольные, обход CCW снаружи, записанные нормали проверены
против геометрического обхода.

| Файл | Треугольники | Габариты, м |
|---|---:|---:|
| `надгробие_плита.obj` | 56 | 0.76×0.92×0.34 |
| `надгробие_крест_камень.obj` | 68 | 0.74×1.14×0.36 |
| `надгробие_обелиск.obj` | 40 | 0.58×1.04×0.48 |
| `надгробие_покосившееся.obj` | 60 | 0.70×0.95×0.18 |

`models-preview.png` — нейтральная ортографическая проверка силуэтов.

## Воспроизводимость

```sh
python3 tools/graveyard-assets/prepare_texture.py composite BASE EDIT OUT
python3 tools/texture-prep.py OUT textures/земля_утоптанная \
  --target 0.22 --strength 0.7 --size 1024 \
  --maps=color,normal,height,rough
python3 tools/graveyard-assets/prepare_texture.py calibrate \
  textures/земля_утоптанная.jpg textures/земля_утоптанная.png
python3 tools/graveyard-assets/generate_tombstones.py
python3 tools/graveyard-assets/render_obj_preview.py \
  docs/art/graveyard-battle-v1/models \
  docs/art/graveyard-battle-v1/models-preview.png
```
