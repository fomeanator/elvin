# Где что живёт: карта домов

Правило одно: **у понятия один дом**. Число, описывающее вид или ритм, не
живёт в методе экрана — оно живёт в доме, откуда его читают все.

Почему это правило, а не вкусовщина: подобранное на месте число нельзя ни
найти, ни изменить осознанно. К августу 2026 «на сколько приблизить фигуру»
существовало тремя наборами чисел в одном методе, «ось про волосы?» — двумя
копиями в двух пакетах, а темп движения — одной константой, размноженной по
десяти умножениям, половина которых про него забывала.

## Дома

| Дом | Что в нём | Настраивается из |
|---|---|---|
| `LvnStyler` | **вид по роли**: `Primary`/`Quiet`/`Ghost`/`Choice`, `Card`, `Pill`, `Track`/`Fill`; `Plate`/`Skinned` — когда палитру приносит новелла | статический; ставит только плашку, чернила, кромку и скругление — компоновка остаётся экрану |
| `LvnCostumer` | **облик героя**: что видно на оси (`Chosen`, примерка сильнее надетого), что зафиксировано (`Committed`), полный набор осей для сцены (`Look`) | статический; каталог по облику собирает слои сам |
| `LvnScreenDirector` | **экран**: режим (глава или меню), скрытие интерфейса ПО ПРИЧИНАМ (катсцена, «во весь рост», разглядывание арта), стопка поверхностей и куда ведёт «назад» | `LvnScreenDirector.Current`, событие `Changed`; `InChapter`/`SetChapter`, `HideChrome(reason)`, `Open`/`Close(surface)`, `SceneSurfaceOpen`, `BackTarget` |
| `LvnStageClock` | **порядок во времени на сцене**: эпоха сцены, дорожки «важен только новейший» (актёр, фон, ожидание), барьеры «до этого момента не начинать» (уход, видимость, кроссфейд облика) | время подменяется в тестах через `Now` |
| `LvnMotion` | **время и физика движения UI**: прайс-лист длительностей (`Instant/Quick/Normal/Reveal/Calm/Notice/NoticeLong`), пружина, проявления, плавная смена стиля, «сказал и вернул» | `LvnMotion.Tempo` — одна ручка на всё, меняется на лету |
| `VnTheme` | **постановка новеллы**: цвета и метрика диалога, кадр актёра, переходы, темп сцены (`Motion`/`MotionMs`), длительности смены облика | `ui.stage`, `ui.dialogue`, `ui.choices` |
| `Placement` / `WorldPlacement` | **где и какого размера объект на сцене**: доли экрана, аспект-бокс, габарит фигуры внутри холста | команда скрипта, `ui.stage.actor_*`, каталог (`aspect`, `content`) |
| `LvnMenuStage` | **витрина меню**: рост куклы, переезд полотна по вкладкам, терпение сторожей сцены, бут-вуаль | `ui.browse.doll_*`, `ui.browse.canvas_pan*` |
| `LvnWardrobeStage` | **витрина гардероба**: чем является ось (волосы / украшение / одежда), её значок, кадр плитки, компоновка колонки эмоций | `ui.wardrobe.framing` |
| `LvnTokens` / `LvnTheme` | **палитра и огранка оболочки**: цвета, радиусы, типографская шкала, отступы, дорожка шкалы (`Track`), затемнение любой плотности (`Veil(alpha)`) | `ui.browse.theme` и поштучные `*_color` |
| `LvnWalletPill` | **плашка кошелька**: значок валюты, число, отсчёт до восполнения, кнопка «+». Экран задаёт только метрику через `Look` | `ui.hud`, `ui.wardrobe`, `ui.browse.currencies` |
| `LvnWallet` | **деньги**: балансы, инвентарь, восполнение и `Display` — как баланс выглядит игроку | сервер + офлайн-зеркало |
| `LvnIcons` | **значки**: векторы вместо шрифтовых символов, значок валюты (`ForCurrency`) | — (набор закрыт намеренно) |
| `LvnPrefs` | **выбор игрока**: громкости, язык, скорость текста, комфорт-настройки | сохраняется на устройстве |
| `LvnPrima` | **постоянная фигура сцены** (героиня): кто она (`Cast`), где стоит (`Place`), перед всеми ли (`z`), беречь ли её арт (`Keep`), цела ли (`Whole`). Команду из настроек собирает единственный метод `Pose` | `ui.browse.doll_*` через `LvnMenuStage` |
| `LvnWords` | **подписи движка**: `Of(key, fallback)` — слово новеллы, иначе умолчание вызывающего; шаблон с числом («День {0}»). Текст новеллы сюда не ходит | `ui.words` |
| `LvnCaptions` | **как зовут главу**: `Chapter` (имя эпизода → «Глава N» → id) и `ChapterNumberOnly` (для титра). Слово — из манифеста, умолчание английское | `ui.chapter_word` |
| `LvnPlayerName` | **как зовут игрока**: `Current` (введённое имя), `Display` (имя или подпись безымянного), `Set`. Подпись — из манифеста, движковое умолчание английское | `ui.guest_name` |
| `LvnGatekeeper` | **что открыто**: глава (`ChapterOpen` — первая всегда, дальше по дошедшему) и новелла (`TitleLocked` — авторское `unlock` над `global.*`; сломанное выражение не закрывает игру) | `title.unlock` |
| `LvnPriceTag` | **облик денег**: подпись валюты, форма при сумме, значок, цвет (`Of`), готовые строки `Amount`/`Full`. Слова — из манифеста, движок знает только форму | `ui.currency_look` |
| `LvnEdges` | **кромки экрана**: вырезы в единицах панели (`Insets`), отступ по назначению поверхности (`Top`/`Bottom` с минимумом и воздухом), подписка `Follow` — будит на привязке, геометрии и тике (поворот/складка событий не дают) | `HomeTopMin`, `PageTopMin`, `PageTopAir`, `NavBottomAir` |
| `LvnUsher` (`ILvnEntrance`) | **вход в меню**: заряжает поверхности (хаб, верхний бар) за кромки, держит дверь, пока идёт бут-вуаль, показывает экран и двигает всех одним движением, ставит единственный предохранитель. Поверхность знает своё движение, Швейцар — порядок и момент | `LvnMotion.Curtain` (общий такт полос) |
| `LvnHealer` | **самолечения сцены**: реестр недугов (как заметить + как лечить + сколько терпеть), разрежение попыток по неизлечимому, `Journal()` — что чинилось само | `LvnMenuStage.Guard*` для витрины |
| `ContentLoader.SpriteCache` | **память под картинки**: бюджет по устройству, давность запроса, вытеснение старейшего и ПИН — пока сцена держит спрайт, его не уничтожает ни один путь выгрузки | `SpriteCacheBudgetBytes` (сам подстраивается под RAM) |
| `LvnLog` | **журнал**: `Trace` — разговор движка с собой (слышен в редакторе, молчит в собранной игре), `Info` — вехи, важные и в поле, `Warn`/`Error` — происшествия | `LvnLog.Verbose`, меняется на лету |

## Как добавить настройку

1. Значение по умолчанию — в дом, полем с комментарием, **зачем** оно такое.
   Дефолт обязан покрывать обычную игру: манифест не должен знать про
   механику, чтобы игра выглядела правильно.
2. Перекрытие — нулевым полем (`float?`) в соответствующем конфиге
   `LvnUiConfig`, с тем же именем, что ключ в манифесте.
3. Применение — там, где манифест уже применяется (`VnThemeBuilder.From`,
   `NovelApp.ApplyMenuStaging`). Обе точки — и загрузка, и живое
   обновление, — иначе «поменять на лету» окажется неправдой.

## Чего не делать

- Не подбирать число в методе экрана «на разок»: разок не бывает, а через
  месяц его не найдёт никто, включая автора.
- Не копировать правило в соседний пакет, потому что «оно приватное». Если
  правило нужно двоим — оно переезжает в дом, а не размножается.
- Не заводить новый дом там, где подходит существующий. Пять домов с ясной
  границей лучше одного «общего конфига», но и лучше пятнадцати.

## Крупные классы разложены по темам

Файл в тысячу строк — это не «большой класс», а несколько классов, которые
забыли разделить. Там, где темы самостоятельные, они лежат отдельными
partial-файлами с общим именем: искать нужное по имени файла, а не поиском по
имени метода.

| Класс | Файлы |
|---|---|
| `NovelApp` | `.Menu` витрина, `.Chapter` вход в главу, `.Wardrobe` два входа в лист, `.Storage` мегабайты, `.Music` трек меню, `.Player` профиль и кошелёк игрока, `.State` переменные и сейвы |
| `NovelShell` | `.Navigation` вкладки и модалки, `.Flow` главный цикл игры |
| `WardrobeSheet` | `.Buy` выбор и покупка, `.Strip` витрина и колонка эмоций |
| `StageMenu` | `.Saves`, `.Gallery` (галерея и история), `.Stats`, `.Settings` |
| `SettingsScreen` | `.Device` диск, качество арта, кадры, покупки; `.Account` кто вошёл, что за сборка, ссылки |
| `TitleDetailScreen` | `.Restart` сохранения, переигровка и выбор главы заново |
| `ProfileScreen` | `.Account` идентификатор, ссылка в настройки, удаление аккаунта |
| `ContentLoader` | `.Fetch` доставка байтов и офлайн, `.Sprites` память и вытеснение, `.Ktx2`/`.Astc` транскоды |
| `VnStage` | `.Actors` тракт показа, `.Actors.Placement` разбор команды, `.Actors.Wardrobe` примерка на сцене, `.Background`, `.Commands`, `.Dialogue`, `.Playback`, `.Pointer`, `.Preload`, `.Spine` |

Правило простое: тема уезжает в свой файл, когда её можно описать одной
фразой и прочитать целиком. Перенос всегда чистый — из исходного файла только
удаления; если при переносе что-то «пришлось поправить», это уже не перенос и
делается отдельным шагом.
