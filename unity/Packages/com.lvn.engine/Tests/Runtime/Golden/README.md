# Золотые кадры

Эталоны PlayMode-сверок (`TestPixels.AssertGolden`) лежат здесь, но в репозиторий
НЕ выгружаются: это двоичные файлы с партнёрским артом, а репозиторий публичный
(`qa/leak-scan.sh` их не пропустит). Без эталона тест ПРОПУСКАЕТСЯ, не падает.

Записать эталоны на своей машине: `LVN_GOLDEN_WRITE=1 qa/run-all.sh --playmode --filter …`,
затем смотреть глазами (`qa/prebuild.sh`).
