// Кавычки и ёлочки внутри ЗНАЧЕНИЯ поля — данные автора, а не синтаксис.
// Оба компилятора обязаны читать этот файл одинаково; до сентября 2026 они
// читали его тремя разными способами, и все три молчали.

// 1. Открывающая ёлочка внутри "…" не открывает многострочную прозу:
//    развороты блоков ниже обязаны сработать, а не стать репликами.
say text="«Не уходи"
if courage > 0 {
Анна: Я осталась.
} else {
Анна: Я ушла.
}

// 2. Двойная косая внутри "…" — часть текста, а не начало комментария.
Анна: "смотри // это не комментарий"
hint text="жми A // или B" duration=3

// 3. Адрес с протоколом переживает то же самое.
bg id=street sprite_url="https://example.org/bg/street.png" // подпись снаружи

// 4. А голая ёлочка ВНЕ кавычек по-прежнему открывает многострочную прозу.
Анна: «Первая строка,
вторая строка.»
Анна: Конец.
