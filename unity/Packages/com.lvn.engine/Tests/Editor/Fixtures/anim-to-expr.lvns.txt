# Цель анимации СЧИТАЕТСЯ, а не задана числом: полоса здоровья тянется к доле,
# которую ещё предстоит вычислить. Компилятор выражение не трогает — переменные
# появятся только во время игры; он переносит его в трек, а игрок подставляет
# число перед самым запуском.
:start
set key=hp value=40
set key=hp_max value=100
anim id=bar prop=scalex to="{hp / hp_max}" dur=0.6
anim id=bar prop=alpha to=0.5 dur=0.2
Лекарь: Полоса поехала.
