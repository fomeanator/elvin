# Реакции героини витрины — шаблон

Героиня на витрине (главная, магазин, гардероб, профиль) отзывается на то, что
делает игрок: встречает при запуске, скучает без внимания, радуется покупке.
Реакции — обычный сценарий `.lvn` с метками; движок трогать не нужно.

Включается манифестом:

```json
"ui": { "browse": {
  "reactions":  "/content/menu-reactions.lvn",
  "idle_after": 10
} }
```

Файл рядом — `menu-reactions.lvn` — рабочий шаблон Time Romance. Скопируйте,
замените `victoria` на имя своей героини и подберите лица под свой каталог.

## Что такое реакция

`actor id emotion=…` **без геометрии** — это выражение лица, а не команда
сцене (`LvnFace`): оно не двигает фигуру, не записывается в облик и уступает
тому, что игрок выбрал сам в гардеробе. Хотите, чтобы реакция двигала героиню —
напишите `x=` или `position=` явно, тогда команда пойдёт сценой.

`wait ms=…` — пауза; клип идёт до следующей метки. `say`/`choice` в витрине
пропускаются.

## Метки

| Метка | Когда | Вид |
|---|---|---|
| `on_launch` | первый показ витрины после запуска | действие |
| `on_home`, `on_store`, `on_wardrobe`, `on_profile`, `on_titles` | приехали в комнату (после переезда) | комната — держится, пока игрок там |
| `on_idle` | `idle_after` секунд без касаний | скука — любое касание будит |
| `on_purchase` | купили что-то | действие |
| `on_equip` | надели вещь | действие |
| `on_return` | вернулись из главы | действие |
| `on_tap` | тап по героине | действие |

Правило: **действие > комната > скука**. Действие доигрывает до конца и
возвращается к настроению комнаты; скука снимается касанием; переезд в другую
комнату обрывает и скуку, и её лицо.

## Лица: что на картинке, а не что в названии

Названия эмоций пришли из articy и не всегда совпадают с тем, что нарисовано.
Проверено по арту Time Romance (11.09.2026):

| Эмоция | На картинке | Где уместна в витрине |
|---|---|---|
| `idle` | спокойный прямой взгляд | главная, покой |
| `medium` | **взгляд искоса**, губы сжаты — не «нейтрально» | «покосилась», вторая стадия скуки |
| `happy` | тёплая улыбка | встреча, возврат |
| `delight` | широкая улыбка, глаза сияют | покупка — самое сильное «да» |
| `flirt` | полуулыбка, бровь приподнята | гардероб |
| `dreamy` | мягкий взгляд вниз | профиль |
| `thoughtfulness` | взгляд вверх-в сторону | список новелл |
| `smirk` | хитрая полуулыбка | магазин, примерка |
| `surprised` | брови вверх, губы приоткрыты | первая доля секунды встречи и покупки |
| `shame` | румянец, взгляд в сторону | тап по героине |
| `boredom` | веки полуприкрыты | первая стадия скуки |
| `sleep` | глаза закрыты | конец скуки; касание будит |
| `discontent`, `offence`, `anger` | нахмурены — на игрока | **в витрине не использовать** |
| `sad`, `tears`, `fear` | сюжетные | **в витрине не использовать** |
| `horny`, `sarcasm` | сюжетные | не для витрины |

## Ритм

- Смена лица ощущается за ~0,3 с; пауза меньше 700 мс между двумя лицами
  читается как мигание — не ставить.
- Действие — 2–3,5 с целиком, иначе игрок ждёт.
- Скука — медленно: 2,5 с → 1,8 с → сон; сон держится до касания (в шаблоне —
  до 12 с, чтобы без касания она тоже проснулась).
- Комната — одно лицо без `wait`: оно держится само.
